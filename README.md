# SaaS Exec Dashboard

A clean, modern SaaS dashboard built with React, Vite, and Tailwind CSS. The application loads data from a CSV file (`/data/sales_data.csv`) and presents dynamic key performance indicators (KPIs) alongside a detailed transactions table.

## Features
- **Dynamic KPIs**: Calculates Total Revenue, Total Orders, Net Profit, and Average Order Value directly from the CSV data.
- **Transactions Table**:## ☁️ Supabase Cloud Database (Recommended)
The backend API is configured to read data from a local CSV by default, but is fully ready to connect to Supabase for a real database experience.

### **Step-by-Step Connection Guide:**
1.  **Create a Project**: Go to [Supabase](https://supabase.com/) and create a new project.
2.  **Create the Table**: 
    - Go to the **SQL Editor** in your Supabase dashboard.
    - Copy and paste the contents of [schema.sql](file:///c:/Users/Tan/Downloads/vc-dashboard/schema.sql) (or the snippet below) and run it:
      ```sql
      CREATE TABLE IF NOT EXISTS sales_data (
        id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        date DATE NOT NULL,
        product TEXT NOT NULL,
        channel TEXT NOT NULL,
        orders INTEGER NOT NULL DEFAULT 0,
        revenue DECIMAL(12, 2) NOT NULL DEFAULT 0.00,
        cost DECIMAL(12, 2) NOT NULL DEFAULT 0.00,
        visitors INTEGER NOT NULL DEFAULT 0,
        customers INTEGER NOT NULL DEFAULT 0,
        created_at TIMESTAMPTZ DEFAULT NOW()
      );
      ```
3.  **Import Data**: Go to the **Table Editor**, find the `sales_data` table, and use the **"Insert" -> "Import CSV"** button to upload your local [sales_data.csv](file:///c:/Users/Tan/Downloads/vc-dashboard/public/data/sales_data.csv).
4.  **Get your Credentials**: Go to **Project Settings -> API** to find your **URL** and **Anon Key**.
5.  **Connect Local API**: In your local `.env` file, add your credentials and set the `DATA_SOURCE`:
    ```bash
    DATA_SOURCE=supabase
    SUPABASE_URL=your_project_url
    SUPABASE_ANON_KEY=your_anon_key
    ```
6.  **Restart**: Restart your development server (`npm run dev`). The API will now serve data directly from Supabase!

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the localhost port provided in the terminal (e.g., `http://localhost:5173/`).

## Project Structure
- `src/components/Dashboard.jsx`: Contains the main layout, table UI, KPI calculation logic, and CSV fetching.
- `public/data/sales_data.csv`: The raw input data loaded by the app.
- `src/index.css`: The root stylesheet importing Tailwind utility classes.
